## Reproduction and distribution

Run `node scripts/generate-brand-assets.mjs` from the repository root with the existing Playwright installation. This performs only literal palette replacements, then renders the primary through Chromium at 16, 32, 48 and 128 pixels into `apps/extension/public/icon/`. WXT uses those PNGs in both browser manifests. SVG remains the master; PNGs are distribution derivatives only.

`generated-icons.json` records the source hash, renderer version and generated byte hashes. Repeated generation with that renderer is deterministic. Different Chromium versions may rasterize edges differently; regenerate and review the manifest and PNGs together when upgrading. The immutable source and generated SVGs are excluded from automatic formatting to preserve their bytes. Unit tests enforce the source hash and exact palette-only substitutions.
