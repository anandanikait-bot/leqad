## Future adapter boundary

Onshape-specific recognition, target mapping, UI observations and browser lifecycle
remain in `apps/extension`. Shared lesson transitions, contracts and CAD policy
contain no DOM, browser or Onshape-selector dependencies. A future CAD adapter
must provide context identity, supported UI observations, target resolution and
fresh model facts with explicit provenance. No new abstraction or other-platform
implementation is introduced in this sprint.
