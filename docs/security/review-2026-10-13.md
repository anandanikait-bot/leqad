## Runtime data

Leqad stores panel preferences, learning history, and per-document lesson sessions in extension local storage. Stored evidence references and observations may include synthetic or Onshape document identity fields. The extension should avoid exposing those values in logs, screenshots, issues, or telemetry if a future service is added.

## Open items

- Live browser validation must confirm that no Onshape account or document identifiers appear in user-facing diagnostics.
- A future API integration needs a separate authentication, token-storage, request-scope, and revocation review.
- A future AI service needs prompt/data minimization, output handling, telemetry disclosure, and protection against unsafe execution.
- Dependency and platform advisories should be reviewed continuously in CI or repository security tooling.

This review does not claim penetration testing or live Onshape security validation.
