# Official Leqad logo baseline

**Decision:** October 23, 2026. The circular engineered emblem and heavy geometric "Leqad" lockup are the only active brand master. The center is **Hay's Russet `#793327`**.

Palette: primary navy `#0E2943`, ivory `#F5EFE7`, russet `#793327`. See the official matching assets in `apps/extension/src/assets/brand/` and in the website repo `public/assets/brand/`.

- Navy version for light backgrounds; ivory version for navy backgrounds.
- Use the **entire approved wordmark** image, never recreate it using generic text or the old boxed-letter L icon.
- For compact application icons, use the approved symbol-only silhouette.
- True SVG paths are digitized from the owner-approved October 2026 raster, not original illustrator source.
- Keep earlier branding references in preserved historical design documents untouched as provenance, but no active UI should use them.
- This baseline also applies to the planned cross-CAD desktop companion; new interfaces must reuse the same vector assets rather than inventing alternatives.
- The prior UI rust `#B74B21` is not the logo's Hay's Russet; do not globally retheme unrelated interaction colors.

Brand source of truth: [Leqad website official logo documentation](https://github.com/anandanikait-bot/Leqad-website/blob/feat/official-logo-russet-v1/docs/branding/official-logo.md).
