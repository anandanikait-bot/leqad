Find Corner rectangle with Onshape Search Tools

Corner rectangle uses two opposite corners. It fits this lesson's simple rectangular profile. Center point rectangle starts from its center; it is a different tool.

  1. In your disposable Onshape document, manually enter Sketch editing on the intended plane. This page cannot detect your current editor or permissions.
  2. In Onshape, open Search Tools at the right of the toolbar. The documented shortcut is Alt + C on Windows or Option + C on macOS. If hidden, check the toolbar's right-click options. Your shortcut configuration may differ.
  3. Type Corner rectangle. Read the result's name and description. Do not substitute another Rectangle variant or assume the visible group icon is the required variant.
  4. If offered, enable Highlight tool in toolbar and hover the exact result to see Onshape's own highlight. This does not establish a dropdown-arrow boundary for Leqad.
  5. Only if the exact command is available in the intended Sketch context, manually select it in Onshape and draw the two opposite corners. This page never clicks a CAD control.

If the command is not available

Press Escape to close search. Check the editor and access with your instructor. Do not choose a similar result just to continue. Written instructions remain available even when Leqad cannot identify the control.
